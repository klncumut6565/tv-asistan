Jülide · API anahtarı kurulumu

Jülide, sizin kendi ücretsiz Google Gemini anahtarınızla çalışır.

  1. Aşağıdaki düğmeyle Google AI Studio'yu açın ve Google hesabınızla giriş yapın.
  2. Create API key (API anahtarı oluştur) düğmesine basın.
  3. Oluşan anahtarın yanındaki kopyala simgesine basın ve bu sayfaya dönün.
